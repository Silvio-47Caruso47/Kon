# Эмулятор оболочки ОС

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Реализован на Python с использованием библиотеки Tkinter.

## Общее описание

Программа представляет собой REPL (Read-Eval-Print Loop) — цикл
«прочитай → выполни → покажи». Пользователь вводит команду, программа
её разбирает на имя и аргументы и выполняет.

Реализованные команды:
- `ls` — заглушка, выводит своё имя и аргументы.
- `cd` — заглушка, выводит своё имя и аргументы.
- `exit` — закрывает приложение.

## Описание функций и настроек

**`parse_command(line)`** — разбирает строку на команду и аргументы
по пробелам.

**`run_command(command, args)`** — выполняет команду. Возвращает пару:
текст ответа и флаг «закрыть окно».

**`main()`** — создаёт окно, размещает элементы и запускает цикл событий.

Настройки окна:
- Заголовок формируется автоматически: `Эмулятор - [username@hostname]`.
- Размер окна: 700x500 пикселей.
- Поле вывода: 20 строк, 80 символов.
- Поле ввода: 80 символов.

## Команды для сборки и запуска

Python 3.10+ (проверено на 3.13).
